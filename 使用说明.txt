================================================
  GitHub 自动登录工具 - 使用说明
================================================

【前提条件】
- 安装 Python 3.8 或更高版本
- Windows: https://www.python.org/downloads/ (安装时勾选 "Add Python to PATH")
- Mac/Linux: 系统一般自带，或用 brew install python3 / sudo apt install python3

【启动方式】
- Windows: 双击 "启动.bat"
- Mac/Linux: 终端运行 bash 启动.sh

【使用方法】
1. 启动后浏览器自动打开 http://localhost:5000
2. 在输入框中按以下格式输入（每行一个账号）:

   账号----密码----TOTP密钥

   例如:
   example@gmail.com----mypassword----X4TFJHJUNRTVJYVI

3. 点击"登录"按钮
4. 下方日志区域显示登录进度和结果

【文件说明】
- github_login_web.py  → 主程序
- 启动.bat             → Windows 一键启动脚本
- 启动.sh              → Mac/Linux 一键启动脚本
- 使用说明.txt          → 本文件
